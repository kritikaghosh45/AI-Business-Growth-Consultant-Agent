# Contributing to AI Business Growth Consultant Agent

Thank you for your interest in contributing to this project. Contributions are welcome in the form of bug fixes, documentation improvements, and feature ideas.

## How to contribute

1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Make your changes.
4. Open a pull request with a clear description of your improvement.

## Guidelines

- Keep code readable and well-commented.
- Add documentation for new features.
- Provide example input/output if relevant.
- Ensure any added Python code follows the style used in `agent.py`.

## Reporting bugs

If you find an issue, please open a GitHub issue with steps to reproduce and expected behavior.
