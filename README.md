# AI Business Growth Consultant Agent

This project demonstrates a Python-based AI Business Growth Consultant Agent that evaluates a company profile and generates growth recommendations for marketing, sales, product, and operations.

## Structure

- `agent.py` - Core consultant agent logic and CLI interface.
- `report.md` - Project report with objectives, architecture, and sample outputs.
- `requirements.txt` - Optional dependencies.

## How to run

1. Open a terminal in `AI_Business_Growth_Consultant`.
2. Run:

```bash
python agent.py
```

3. Follow the prompts to generate a growth plan for a sample business.
